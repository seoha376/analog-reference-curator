# Analog Cute Web Template Candidates

수집일: 2026-08-12

목표 취향: 아날로그한 텍스트, 아기자기함, 오밀조밀한 정보 밀도, 밤티/미국 SaaS 랜딩 느낌을 피한 웹 UI.

사용법:

- `KEEP`로 바꾸면 다음 템플릿 제작 때 살릴 후보.
- `KILL`로 바꾸면 다시 보지 않을 후보.
- `MAYBE`는 더 훑어볼 후보.

## 빠른 결론

가장 잘 맞는 소스는 일본 웹 디자인 갤러리와 Neocities/handmade web 계열이다. 미국식 SaaS 템플릿 마켓은 구조 참고용으로만 쓰고, 실제 미감은 일본 소규모 브랜드/문구/푸드/잡화/개인웹에서 가져오는 쪽이 좋다.

## 취향 추출 체크리스트

살릴 후보를 볼 때 아래 요소만 따로 표시하면 템플릿화가 쉬워진다.

- Typography: 손글씨풍 제목, 작은 본문, 일본 잡지식 조밀한 캡션, 세로쓰기 가능성
- Layout: 좁은 그리드, 사이드바, 작은 배지, 스티커처럼 붙은 이미지, 카드보다 “종이 조각”
- Texture: 종이, 스캔, 도트, 얇은 라인, 잉크 번짐, 미세한 그림자
- Motion: 느린 호버, 스티커가 살짝 들리는 정도, 과한 3D/패럴랙스 금지
- Components: 작은 알림장, 문구점 라벨, 영수증, 우표, 책갈피, 미니 탭, 콜라주 썸네일
- Avoid: 거대한 히어로, 과한 그라디언트, 둥근 SaaS 카드 남발, 어두운 네이비 대시보드, 미국식 스타트업 카피

## 다음 템플릿 후보군

1. Stationery Desk
   - 문구점/노트/스티커 느낌.
   - 좋은 용도: 개인 포트폴리오, 작은 브랜드, 프로젝트 허브.

2. Tiny Magazine
   - 일본 잡지 목차 같은 조밀한 레이아웃.
   - 좋은 용도: 블로그, 큐레이션, 기록장.

3. Soft Shop Shelf
   - 작은 상품들이 선반에 놓인 듯한 EC/카탈로그형.
   - 좋은 용도: 굿즈, 디지털 제품, 추천 리스트.

4. Night Letter
   - 밤 느낌은 유지하되 미국식 dark SaaS가 아니라 편지지/책상 조명 쪽.
   - 좋은 용도: 메모 앱, 독서 기록, 개인 작업실.

5. Local Poster Board
   - 동네 게시판, 전단지, 작은 이벤트 포스터 느낌.
   - 좋은 용도: 커뮤니티, 클래스, 행사, 로컬 프로젝트.

## 추천 수집 루프

1. 위 갤러리에서 20-40개 후보를 훑는다.
2. 마음에 드는 항목만 `KEEP`로 바꾼다.
3. `KEEP` 후보에서 공통 UI 요소를 5개 이하로 뽑는다.
4. 그 요소를 기반으로 HTML/CSS 템플릿 2-3개를 만든다.
5. 실제 브라우저에서 모바일/데스크톱 스크린샷으로 비교한다.
